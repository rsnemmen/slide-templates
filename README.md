Slide template: assertion-evidence design
===========================================

This is slide template for scientific presentations based on the well-known assertion-evidence design advocated by Michal Alley. I first took his course when I was in Penn State and have been basing my presentations and lectures on this design my alnost two decades. It works. I like it because it is clean and simple. 

Feel free to download the keynote file and change it as you wish. Inspired on [this repository](https://github.com/hplgit/MAlley-slide-templates).
